## 1. 模块整体架构

### 1.1 菜单结构（售电业务 > 仿真平台）

录屏中仿真平台下有 **3 个子页面**（现有代码只有 2 个，且命名不同）：

| 录屏菜单项 | 现有代码菜单项 | 现有 pageKey | 差异 |
|---|---|---|---|
| 现货仿真回测 | 现货交易仿真 | spot-trading-simulation | 改名 + 重做 |
| 现货模拟交易 | 现货模拟交易 | spot-mock-trading | 同名 + 重做 |
| 交易决策分析 | （无） | （需新增） | 新增页面 |

> ⚠️待确认：「交易决策分析」在录屏中作为菜单项出现，但未见其独立页面标题大字画面；~220s 的「策略收益分析」对比视图可能即该页内容，或录屏未演示。暂列为待确认的第 3 个页面。

### 1.2 通用布局规范

所有页面共享：
- 顶栏：BOSS logo + 顶部导航（体验中心/效能中心/安全中心/文化中心/学习中心/合规中心/HRD 等）+ 右上交易中心切换 + 功能检索 + 用户头像
- 左侧：售电业务侧边栏菜单（仿真平台位于「售电业务」分组下）
- 交易中心切换：页面标题右侧「广东电力交易中心」（可切陕西等）
- 页面骨架：`page-stack` > 标题区 > 筛选区 > 内容区（卡片/图/表）

## 8. 数据需求（前后端补充）

需在 `src/mock/simulationData.js` 重构/新增以下数据结构：

5. **策略收益分析序列** `spotMockTrading.profitSeries[]`：每策略每日累计收益 + 每日收益 + 实际申报基准 + 数据来源标注。

## 9. 实现约束

- 纯静态 IIFE，挂 window 全局，无构建步骤（见 `docs/memory/project-memory.md`）。
- 新增页面遵循：pageRegistry → platformMenu → pageState → main.js renderContent → index.html 顺序。
- 复用既有组件：renderDataTablePro / renderChartWithMarks / renderBarChart / renderStandardDatePicker / renderSummaryCards / renderSectionTable / renderTradeCenterSelector / drawer 与 modal overlay 机制。
- 颜色用 styles.css :root 设计 token，不硬编码 hex。
- 不改动 BOSS 其它页面。
- 交易中心切换复用现有 `getSelectedTradeCenterKey` / `renderTradeCenterSelector` 机制。
